## 1. Difference between Google Knowledge Graph and Google Knowledge Panel

The **Google Knowledge Graph** is a database of entities and their relationships that Google uses to understand information.
The **Google Knowledge Panel** is the visual representation of that data shown on the search results page.

---

## 2. How Google Determines Entity Identity

Google determines entity identity through a combination of:

* Structured data (schema markup)
* Consistent Name, Address, and Phone (NAP) information
* sameAs links connecting profiles
* Mentions across authoritative websites
* Data from trusted sources (e.g., Wikidata, Google Business Profile)

---

## 3. When to Create Custom Post Types Instead of Pages

Custom Post Types should be used when content is:

* Repetitive and structured (e.g., property listings)
* Requires custom fields or metadata
* Needs its own taxonomy (categories/tags)
* Managed separately from regular pages

## 4. Recommended Plugins for Speed Optimization and Why

* **WP Rocket** – Comprehensive caching, file optimization, and lazy loading with minimal configuration
* **LiteSpeed Cache** – Server-level caching with advanced performance features (best on LiteSpeed servers)
* **Autoptimize** – Optimizes and minifies CSS, JavaScript, and HTML to reduce load time

These plugins improve performance by reducing load time, optimizing assets, and enhancing Core Web Vitals.
